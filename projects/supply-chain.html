Supply Chain Analytics Dashboard

A BI dashboard tracking stock-out risk, warehouse utilization, and supplier/carrier performance across a warehouse network.

Python Pandas PostgreSQL SQLAlchemy Power BI OpenPyXL

Overview

An end-to-end data analytics project tracking inventory health, supplier performance, and shipment delays across a network of warehouses and suppliers in India. The project generates realistic synthetic data, loads it into a PostgreSQL relational database, runs business intelligence queries, and delivers insights through an interactive Power BI dashboard and an exported Excel report.

Technology Stack

Data Generation

Python 3 · Pandas · NumPy · Faker (en_IN) with fixed seed for reproducibility.

Database

PostgreSQL with SQLAlchemy ORM, six core tables with foreign-key relationships.

Analysis

Eight SQL business-metric queries; results exported to a multi-sheet Excel workbook.

Visualization

Microsoft Power BI (.pbix) interactive dashboard.

Dataset

10 warehouses, 50 suppliers, 300 products, 300 inventory records, 2,000 purchase orders, and ~1,300 shipments — about 3,960 records across six tables.

Key Insights

Inventory health by status (Low Stock / Overstock / Healthy), warehouse utilization levels bucketed as Critical/High/Medium/Low, carrier reliability and shipment delays, and monthly procurement spend trends.
