Credit Risk Prediction System

An end-to-end machine learning system that classifies loan applicants into High Risk or Low Risk categories to support better credit approval decisions.

Python PostgreSQL Pandas NumPy Scikit-Learn XGBoost FastAPI

Overview

A complete end-to-end ML system for predicting customer loan default risk. The pipeline ingests raw source files, engineers features, stores them in a customer-level feature store, and exposes predictions through a real-time API.

Architecture

CSV files → PostgreSQL Database → Feature Engineering → Feature Store → ML Pipeline → FastAPI API → Real-time Predictions.

Key Features

Data Engineering

Loaded 11 source files into PostgreSQL; built a feature engineering pipeline and a customer-level feature store.

Machine Learning

Trained Logistic Regression, Random Forest and XGBoost; evaluated with Accuracy, Precision, Recall, F1 and ROC-AUC. Pre-trained XGBoost ready for inference.

Deployment

FastAPI REST API with Swagger UI, real-time risk prediction endpoint, and error handling for not-found scenarios.

Sample API Response

{ "customer_id": 100002, "default_probability": 0.88, "prediction": "High Risk" }

Dependencies

pandas, numpy, scikit-learn, xgboost, sqlalchemy, psycopg2-binary, fastapi, uvicorn, joblib, jupyter, notebook.
